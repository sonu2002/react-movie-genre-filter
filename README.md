# 🎬 Top Movies: React Genre Filter

A small **React + Tailwind CSS** app listing the **top 15 movies of all time**, with a genre filter.

🔗 **Live demo:** https://sonu2002.github.io/react-movie-genre-filter/

## ✨ Features
- Movie list rendered from a local data module
- Genre filter built with React `useState` and derived state
- Responsive styling with **Tailwind CSS**

## 🛠️ Tech stack
`React` · `Vite` · `Tailwind CSS` · `PostCSS` · `Prettier`

## 🚀 Run locally
```bash
npm install
npm run dev
```
